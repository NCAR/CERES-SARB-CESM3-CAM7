## Implemented

- `aod_optics_method = 'remap'|'lut'` is namelist-controlled. `remap` remains the default.
- Empty `aod_optics_band_file` now selects hard-coded SARB/LFL bands; a non-empty path still overrides.
- `remap` uses the regenerated v2 CAM-LW omega/g table at `/glade/work/fillmore/Data/CERES-SARB-CAM7/optics/aod_lw_omega_g.nc`.
- `lut` reads an LFL-native Chebyshev/Mie table and evaluates CAM MAM4 wet aerosol state directly on the 14 SW + 12 LW LFL bands.
- LUT coefficients are generated by the local lognormal radius-grid integration in `sp3_optics/make_lfl_lut.py`, using MAM-LFL `mie_sphere.py` single-radius cross sections; the table `mie_source` attribute records this path.
- The writer adds `method`, `lut_file`, and `lut_table_version` global attributes.
- Deploy patch files are idempotent against the beta08 CAM checkout.

## Visible AOD Gate Note

CAM7/RRTMGP `AODVISdn` is a diagnostic for the CAM visible band containing 500 nm, not a narrow 550 nm sample and not identical to LFL `SW05` alone. In this case that CAM band maps to the legacy physprop SW band 10 and overlaps LFL `SW04`, `SW05`, and `SW06`. The comparison tool therefore reports both raw LFL `SW05` and a `CAMVIS` overlap average. The raw `SW05` value remains useful as the SARB band value; `CAMVIS` is the like-for-like consistency gate against `AODVISdn`.
