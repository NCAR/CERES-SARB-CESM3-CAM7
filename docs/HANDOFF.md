### One-paragraph summary of the prior attempt
It constrains CAM6/MAM4 aerosol toward satellite column AOD. Each update step it reads a 3-hourly, f09-gridded merged MODIS+VIIRS AOD field (`MODIS_VIIRS_AOD/{year}/...`, var `aod_weighted_mean`, 550 nm), computes model AOD from the 27 MAM4 species via a re-implemented Köhler+Mie optics path, forms one per-column scalar `AOD_ratio = Target/Computed`, scales **all** species at **all** levels by it, and — despite the name "nudging" — **hard-overwrites** the aerosol state (`nudging_AODs.F90:1907` active; the Newtonian-relaxation path at `:1906` is commented out). MERRA2 met-nudging runs simultaneously. It works in spots but is buried under ~123 near-duplicate module variants, 264 test cases, 5 namelist XMLs, multiple CESM checkouts, no git, and no tests.

### What's worth carrying forward
The **observation archive** (`/glade/work/tvmora/MODIS_VIIRS_AOD/`, 2000–2025, f09, 3-hourly) is a durable asset. The **Mie/LARC optics tables** (`/glade/work/tvmora/Mie_io/mam4_mode[1-4]_larc_c000000.v2.nc`) and the Köhler water-uptake physics are sound — but the rewrite should **call CAM's `modal_aer_opt`/`modal_aero_wateruptake`** instead of duplicating them. The Heaviside windowing, the `&nudging_AOD_nl` namelist pattern, `scatter_field_to_chunk` I/O, time-interpolation, and simultaneous MERRA2 nudging are good *patterns* to keep. Everything else (variant sprawl, duplicated optics, ad-hoc scripts, extra checkouts, fire-emissions dirs) is discard.

## 5. Open decisions (resolve before designing) — full detail in `SYNTHESIS.md §7`

**Base version — DECIDED: CESM3 / CAM7 (`cesm3_0_beta08`).** Rationale: CESM3 is the firm target for production runs, so building on CAM6 would be throwaway. The migration concern is handled by *design* (a CAM-version-abstraction boundary), not by the base choice. Accepted costs: beta is a moving target (pin the tag; rebase deliberately), no CAM6 reference build to diff against, and the radiation/optics stack (RRTMG→RRTMGP, evolved `modal_aer_opt`, MAM4-vs-MAM5) is the part that changed most — hence the spike. Fallback to CAM6 only if the spike finds a blocker.

Other key forks (still open):
1. **Forcing vs. nudging** — hard replacement (prior code) vs true `α·(Target−Model)/τ` relaxation. Biggest science fork.
2. **Increment distribution** — single-scalar column rescale (prior code) vs per-mode/per-species and/or vertical-profile inversion.
3. **Radiative feedback** — should nudged aerosol feed radiation (RRTMGP in CAM7)? **Leans "yes / required"** given the CERES/SARB radiation-budget purpose; confirm.
4. **Optics** — reuse CAM7 `modal_aer_opt`/radiation optics (strongly recommended) vs reimplement. Spike confirms the CAM7 interface.
5. **Obs product** — MODIS-only / VIIRS-only / merged; 550 nm only; QC + obs-error weighting (none today); VIIRS bias-correction (algorithm unarchived — recover or re-baseline); obs-gap behavior.
6. **Grid scope** — f09-only vs arbitrary grids w/ conservative regridding.
7. **Integration** — SourceMods overlay vs clean modular set (`nudging_io`/`nudging_optics`/`nudging_kernel`/`nudging_phys_interface`) with unit+regression tests for eventual branch/upstream merge.
8. **MERRA2 + spin-up** — keep simultaneous met-nudging as a requirement; define a spin-up protocol.
